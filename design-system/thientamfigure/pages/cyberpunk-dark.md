# ThienTam Figure Studio - Dark Cyberpunk & Gaming Design System

## Overview
- **Visual Style**: Dark Cyberpunk & Gaming Studio (Glassmorphic 3D, High-Contrast Neon Accents)
- **Primary Color**: `#E05638` (Vibrant Flame Red / Figure Accent)
- **Secondary Accent**: `#F59E0B` (Neon Star Gold)
- **Background**: `#0B0E17` (Deep Cyber Obsidian)
- **Card Background**: `#141824` with 80% opacity and `backdrop-blur-md`
- **Border**: `#1F293D` with hover glow `shadow-[0_0_25px_rgba(224,86,56,0.3)]`
- **Typography**: Heading: Inter/Montserrat Bold, Body: Be Vietnam Pro / Sans-Serif
- **YouTube Review Accent**: `#EF4444` (YouTube Red) with pulse glow effect

## Component Guidelines
- **Product Card**: Dark glass container (`#141824`), square image with border radius 12px, hover scale 1.05, glowing status badges (PRE-ORDER: Gold `#F59E0B`, MỚI VỀ: Green `#10B981`, DISCOUNTS: Flame `#E05638`).
- **YouTube Player**: Cinematic theater container (`#12141F`), glowing red frame on play, custom duration badge.
- **Buttons**: Glowing neon border or solid `#E05638` with shadow `shadow-lg shadow-red-900/40`.
